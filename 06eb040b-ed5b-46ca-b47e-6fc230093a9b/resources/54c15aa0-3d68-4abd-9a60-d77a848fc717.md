# Backup: engineering stories

| Story | Lesson |
| --- | --- |
| CHECK performance | Benchmarks belong to one implementation and environment |
| Empty strings and ORE | Variants can accept different inputs |
| Credential-tied selectors | Test data must match its cryptographic context |
| Expiring known failures | An expected failure should fail once its bug is fixed |
| Regeneration checks | `git diff --exit-code` misses new untracked files |
| Closed operator enums | Exhaustive matching reduces omissions, not all bad SQL |
