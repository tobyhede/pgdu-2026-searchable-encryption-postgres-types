# The change that hides the index

```sql
ALTER FUNCTION eql_v3.eq(public.eql_v3_text_eq, eql_v3.query_text_eq)
  SET search_path TO public, eql_v3;

-- after the demo
ALTER FUNCTION eql_v3.eq(public.eql_v3_text_eq, eql_v3.query_text_eq)
  RESET search_path;
```

- A function-level `SET` disables inlining
- `col = $1` stays an opaque call and no longer matches the index
