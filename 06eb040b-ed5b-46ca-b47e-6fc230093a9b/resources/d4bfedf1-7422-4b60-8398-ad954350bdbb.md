# Notes: A domain is a representation contract

This is a condensed presentation of the installed definition in `packages/eql/src/v3/scalars/text/text_types.sql`. It is not an instruction to recreate the installed domain.

The CHECK does not establish cryptographic validity, and it does not prove the search term corresponds to the ciphertext.

NULL passes a domain CHECK. Use a column `NOT NULL` when the application needs one.
