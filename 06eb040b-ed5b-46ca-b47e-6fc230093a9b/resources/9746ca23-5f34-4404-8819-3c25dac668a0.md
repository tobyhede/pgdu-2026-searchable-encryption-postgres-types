# Reject what has no meaning

```sql
CREATE FUNCTION eql_v3_internal.eq(a public.eql_v3_integer,
                                   b public.eql_v3_integer)
RETURNS boolean IMMUTABLE PARALLEL SAFE
AS $$ BEGIN
  RAISE EXCEPTION 'operator % is not supported for %',
    '=', 'public.eql_v3_integer';
END; $$ LANGUAGE plpgsql;
```

- Claim the signature so resolution lands **here**
- Raise instead of falling back to `jsonb`
