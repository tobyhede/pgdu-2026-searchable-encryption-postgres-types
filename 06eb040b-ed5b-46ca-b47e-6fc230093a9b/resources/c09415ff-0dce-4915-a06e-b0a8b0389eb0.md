# Stored values vs search operands

| | Storage domain | Query domain |
| --- | --- | --- |
| Schema | `public` | `eql_v3` |
| Ciphertext `c` | required | forbidden |
| Equality term `hm` | required | required |
| Example | `public.eql_v3_text_eq` | `eql_v3.query_text_eq` |

```sql
-- Storage:  VALUE ? 'c'       AND VALUE ? 'hm'
-- Query:    NOT (VALUE ? 'c') AND VALUE ? 'hm'
```
