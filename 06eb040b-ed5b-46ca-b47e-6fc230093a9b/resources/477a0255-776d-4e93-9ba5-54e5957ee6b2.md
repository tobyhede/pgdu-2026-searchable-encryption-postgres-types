# Notes: Ordering: a correctness demo first

The default OPE term is a `bytea` domain and uses native bytea ordering. For numeric and time ordering domains, the ordering term also serves equality.

Bare `ORDER BY col` uses the underlying jsonb ordering in this setup and can silently disagree with value order. Predicate inlining does not rewrite a bare sort key.

The `{2,1}` vs `{1,2}` result came from a PostgreSQL 17 check with controlled integer envelopes. Reproduce with the pinned release and real fixtures before using it on stage.

Matrix tests assert the extractor form only. `sql-support.md` claims bare ordering engages an index; `database-indexes.md` requires the extractor. Follow observed behaviour.
