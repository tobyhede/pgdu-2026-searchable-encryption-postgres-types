# A domain is a representation contract

```sql
CREATE DOMAIN public.eql_v3_text_eq AS jsonb
  CHECK (
    jsonb_typeof(VALUE) = 'object'
    AND VALUE ? 'v' AND VALUE ? 'i'
    AND VALUE ? 'c' AND VALUE ? 'hm'
    AND VALUE->>'v' = '3'
  );
```

- The **name** declares the capability
- The **CHECK** enforces the envelope shape
