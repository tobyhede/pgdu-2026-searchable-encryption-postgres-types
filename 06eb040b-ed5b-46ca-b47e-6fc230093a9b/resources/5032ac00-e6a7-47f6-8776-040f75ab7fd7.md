# Notes: Backup: uniqueness

JSONB equality compares jsonb values, not serialized bytes. Randomized ciphertext means envelope uniqueness doesn't imply plaintext uniqueness.

Term uniqueness equals plaintext uniqueness only with valid, consistently generated terms in the same key and normalization context. It doesn't validate the ciphertext-to-term relationship. Default unique-index NULL semantics apply. Rehearse with two independent encryptions of the same plaintext before calling it the production recipe.
