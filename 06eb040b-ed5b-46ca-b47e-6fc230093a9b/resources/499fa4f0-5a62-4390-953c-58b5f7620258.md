# Notes: The limit of domains

Don't teach "never nest domains" as a universal rule. Exact operator matches can still win; the problem is fallback resolution reaching `jsonb` and skipping the parent domain's operators and blockers.

EQL enforces this with an installed-catalog lint (`packages/eql/src/v3/lint/lints.sql`); `lint_tests.rs` plants a domain over `public.eql_v3_integer` and expects the lint to flag it.

Refs: PostgreSQL docs on domains and on operator type resolution.

Transition: a value can pass its CHECK while a comparison still means the wrong thing.
